GitHub Gist sync

Saved jobs sync through a private GitHub gist. Create a classic token with only the gist scope. It's the same token as your other apps, so if one of them is already connected on this device it's filled in for you. The token is stored only in this browser and is sent nowhere but GitHub.

💾 Back up this token (e.g. in your password manager). GitHub shows it only once, and clearing browser data removes it here — you'll need it to reconnect.

Cloud encryption:

Encrypts the copy stored in your GitHub gist so it can't be read without this passphrase. Use the same passphrase on every device. There's no recovery if you forget it — keep an Export JSON backup. Your data on this device stays readable regardless.

Set-up

  1. Paste your GitHub token (gist scope) and tap Save & sync. Leave Gist ID blank — the app finds its own gist (epdmcalc.json) or creates one.
  2. Do the same on your other device (desktop or Android). It finds the same gist automatically.
  3. Changes merge per job (newest edit wins), so you can work offline on either device and sync later.
