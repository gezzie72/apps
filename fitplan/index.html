Sync across devices (GitHub Gist)

Keep desktop and phone in sync via a private GitHub gist. Create a token with only the gist scope, paste it on each device, and share the same Gist ID. Your token is stored locally in this browser and never leaves it except to talk to GitHub.

Create a token → — use a classic token, tick only gist, then copy it here. (Fine-grained tokens can’t access gists.)
